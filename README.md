# Rocketlane · Interactive Site Map

An interactive force-directed graph visualising the full structure of [rocketlane.com](https://www.rocketlane.com).

**[→ Open the Site Map](https://mukundh-RL.github.io/rocketlane-sitemap/)**

## What it shows
- **108 nodes** across 14 section categories (Product, Industry, Compare, Customers, Blog, Resources, Media, Legal, Community, CTAs)
- **107 links** between pages showing how the site is connected
- Depth levels: Root → Level 1 → Level 2 → Level 3

## How to use
| Action | Result |
|--------|--------|
| **Click a node** | Opens a detail panel — description, all incoming/outgoing links |
| **Click a section in the legend** | Highlights only that section's nodes |
| **Hover** | Tooltip showing page name, section, depth |
| **Drag nodes** | Rearrange the graph |
| **Scroll / pinch** | Zoom in/out |
| **⌖ button** | Fit entire graph to screen |
| **Escape** | Clear current selection |
| **Search bar** | Filter nodes by name or URL |

## Tech
Built with [D3.js v7](https://d3js.org) · No backend · Single HTML file · Data crawled from rocketlane.com
